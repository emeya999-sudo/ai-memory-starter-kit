# AI Memory Starter Kit

A small, file-based way to give one AI assistant useful context about you and your ongoing work.

This kit contains reusable rules, blank templates, and a prompt to personalize them for one AI of your choice. It contains no personal profile or project history. Copy it, then fill in only what you choose to share.

## What it can and cannot do

- It gives you a consistent place to keep notes and instructions.
- It can help an assistant use those notes when you provide the files or when the product gives it access to them.
- It does not automatically sync between chats, assistants, devices, or folders.
- It does not change or override an AI service's built-in system instructions, privacy settings, or product limits.
- Each service's file access and memory features work differently. Follow its current settings and guidance.

## What's inside

- `QUICK_START.md` — a short setup path.
- `PROMPTS/PERSONALIZE_THE_KIT.md` — a prompt for adapting the blank kit to your needs.
- `RULES/` — model-neutral memory rules and an instruction template for your chosen AI.
- `TEMPLATES/` — blank core-memory, project, and conversation-summary files.

This kit is for one AI assistant per copy. If you want to use it with another AI, make a separate copy and personalize that copy for the other assistant.

## Sharing and privacy

Keep your personalized memory files private unless you deliberately choose to share them. Never put passwords, API keys, recovery codes, or other secrets in these files. If you publish an adaptation of this kit, publish the blank templates, not your completed personal memory.
