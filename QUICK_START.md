# Quick start

1. Copy this folder and rename the copy for yourself and the one AI you want to set up.
2. Read `RULES/MEMORY_RULES.md` and choose the parts that suit you.
3. Use `PROMPTS/PERSONALIZE_THE_KIT.md` with that AI, or fill the templates yourself.
4. Keep personal details in your private copy. Leave anything blank that you do not want the assistant to use.
5. Use the prompt to create one instruction file for that AI, named for the AI you chose. Keep it in your private copy of the kit.
6. Give that AI access to the relevant files in the way its product supports. You can also paste the instructions into an available custom-instructions or project-instructions area.
7. At the start of a new chat, check whether the AI can actually access the files. If not, attach or paste only the context needed for that task.
8. After meaningful work, ask the AI to draft a short update. Review it before saving it to your files.

## Start small

Begin with `MASTER_CONTEXT.template.md`, `USER_PREFERENCES.template.md`, and `MEMORY_RULES.template.md`. Add active priorities or project notes only when they are useful. A small, current memory is often easier to use than a large archive. To set up a second AI, start from another clean copy rather than mixing two assistants in one setup.
