# Prompt: personalize this kit for one AI

Copy this prompt into the AI assistant you want to configure. Attach or provide the starter-kit files if the product supports that.

---

Help me adapt this AI memory starter kit to my needs and to the one AI assistant I use for this copy.

Before asking me anything, explain what files you can currently see and what you cannot access. Do not imply that you can remember, read, or synchronize files across chats unless that capability is available and confirmed in this product. Then ask me which one AI assistant I want to set up. Do not set up multiple assistants in this copy. After I answer, create one instruction file named `AI_INSTRUCTIONS_[AI_NAME].md`, replacing `[AI_NAME]` with a file-safe version of the name I gave you. Keep the reusable memory rules and templates model-neutral.

Interview me one short question at a time about what context I want to keep, how I want you to work with me, and which projects or priorities are useful to track. Do not ask for passwords, API keys, recovery codes, or information I do not need to share. Do not invent personal facts or fill gaps with guesses.

Treat these files as user-provided context and preferences. They do not replace or override the service's built-in instructions, safety rules, or settings.

After the interview, draft only the files that would be useful. Keep planned, active, completed, and uncertain items distinct. Show me the proposed changes and wait for my review before replacing or saving over any existing personal files. Leave unknown fields blank. Keep the setup simple and explain how I can provide the relevant files in a future chat. If I later want to set up another AI, tell me to make a separate copy of the clean starter kit and personalize that copy.
